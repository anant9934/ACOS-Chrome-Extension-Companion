# Privacy Policy: Universal AI Context Companion

**Effective Date: May 9, 2026**

The Universal AI Context Companion (the "Extension") is designed with a **Privacy-First, Local-First** philosophy. We believe your code and your conversations are your business.

## 1. Zero Telemetry
The Extension does **not** collect, store, or transmit any personal data, prompts, or source code to external servers. All processing occurs locally on your machine.

## 2. Data Handling
- **Source Code**: Read locally to build semantic graphs. Never uploaded.
- **Prompts**: Captured from browser textareas for optimization. Never uploaded.
- **Memory**: Persistent context and session summaries are stored in your browser's local storage (IndexedDB) and are never synced to the cloud.

## 3. Third-Party Services
The Extension interacts with third-party LLM providers (e.g., OpenAI, Anthropic, Google) only by modifying the content of the prompts you voluntarily submit to their websites. We do not have access to your accounts or API keys for these services.

## 4. Security
We use modern web security standards, including Content Security Policy (CSP), to ensure that the Extension's runtime environment is isolated and secure.

## 5. Changes to This Policy
Any changes to this policy will be reflected in the "Effective Date" above and communicated via the GitHub repository updates.
